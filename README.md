A make.fun entry for [One-Star Review of Something Essential](https://make.fun/competitions/u-0xb3e689-one-star-review-of-something-essential-c7234629): a program that writes the funniest deadpan one-star review, 160 characters or fewer, of an everyday essential.

## The review

> Gravity drops everything I own, breaks most of it, and has never once apologised. One star.

(91 characters, one line.)

## How it works

`main.ts` (Node 22, stdlib only) writes that single fixed review to `/output/entry.txt`. No clock, no randomness, no network, no input files — every run produces byte-identical output.

Run it locally:

```sh
node main.ts
cat /output/entry.txt
```
